# Processed Data

This folder contains cleaned and processed CSV files used in the  Mutual Fund Analytics project.

## Cleaned CSV Files

The folder contains 10 cleaned datasets:

* `clean_fund_master.csv`
* `clean_nav.csv`
* `clean_aum_by_found_house.csv`
* `clean_monthly_sip.csv`
* `clean_category.csv`
* `clean_industry_folio_count.csv`
* `clean_performance.csv`
* `clean_transactions.csv`
* `clean_portfolio.csv`
* `clean_benchmark.csv`

## Analytics CSV Files

The folder also contains processed analytical outputs:

* `returns_computed.csv` — Daily returns and annualised returns
* `cagr_report.csv` — 1-year, 3-year and 5-year CAGR
* `sharpe_values.csv` — Sharpe Ratio
* `sortino_values.csv` — Sortino Ratio
* `alpha_beta.csv` — Alpha and Beta
* `max_drawdown.csv` — Maximum Drawdown
* `fund_scorecard.csv` — Composite fund performance score
* `var_cvar_report.csv` — Historical VaR and CVaR
* `cohort_analysis.csv` — Investor cohort analysis
* `sip_continuity.csv` — SIP continuation analysis
* `sector_hhi.csv` — Sector concentration analysis using HHI
