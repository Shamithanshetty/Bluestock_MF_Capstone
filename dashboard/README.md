# Power BI Dashboard

This folder contains the Power BI dashboard and exported PDF developed for the Mutual Fund Analytics project.

## Dashboard Files

* `bluestock_mf_dashboard.pbix` — Interactive Power BI dashboard containing industry overview, fund performance, investor analytics, and SIP and market trends.
* `bluestock_mf_dashboard.pdf` — PDF export of the Power BI dashboard for reporting and presentation purposes.

## Dashboard Pages

### Industry Overview

Provides an overview of industry-level KPIs including AUM, SIP inflows, folio count, and number of schemes.

### Fund Performance

Presents fund return, risk, Sharpe Ratio, fund scorecard, and NAV versus benchmark analysis.

### Investor Analytics

Analyses investor transactions, age groups, geographic distribution, transaction types, and investor behaviour.

### SIP & Market Trends

Presents SIP inflow trends, NIFTY 50 comparison, category-wise inflows, and SIP account growth.
