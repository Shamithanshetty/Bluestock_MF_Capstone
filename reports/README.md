# Reports

This folder contains the final documentation, presentation, and visualisation outputs for the Bluestock Mutual Fund Analytics project.

## Files

* `Final_Report.pdf` — LaTeX source file for the final project report which converted to pdf file. This file have contents like Executive Summary, Data, ETL, EDA, Findings, Performance Analysis, Dashboard Screenshots, Recommendations, Limitations
* `Bluestock_MF_Presentation.pptx` — Final project presentation summarising the Slide 1: Title Slide 2: Problem & Objective Slide 3: Data Sources Slide 4: Architecture Slide 5-6: EDA Highlights Slide 7-8: Performance Metrics Slide 9-10: Dashboard Screenshots Slide 11: Key Findings Slide 12: Thank You
## Charts

The `charts/` folder contains the visualisations generated during exploratory data analysis and performance analytics.

These charts are used in the final report and presentation.
